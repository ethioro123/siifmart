# SIIFMART Design Standard

The authoritative handbook is [docs/APPLE_DESIGN_GUIDE.md](docs/APPLE_DESIGN_GUIDE.md), edition **29 October 2026**.

Read it before UI work and follow its linked chapters for the affected workflow. This file is a stable repository-root entry point, not a second design specification.

The standard covers visual foundations, adaptive layout, accessible controls, operational tables, approvals, notifications, motion, POS/WMS, performance and release verification. All chapters remain subject to user instructions, `AGENTS.md`, business policy and server-enforced security.
