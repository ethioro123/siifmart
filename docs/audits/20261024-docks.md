# Dock workflow audit — 24 October 2026

## Fixed

- Inbound receipt history no longer treats PO approval as physical unloading. Only partial/complete receipt states qualify. Approval timestamps and approvers are not presented as receipt facts; absent receipt details say Not recorded.
- The dock tab supplies only the active facility's orders to inbound history, as it already did for active arrivals.
- Changing the history search resets pagination.
- Inbound and outbound mutation hooks reject overlapping saves before a second persistence call.
- A refresh failure after a confirmed save is logged separately and no longer reports the saved assignment or shipment action as failed.
- Empty external carrier names cannot be saved from the dock card. Release remains disabled while the typed carrier differs from the saved carrier.
- Mobile dock navigation uses 44px touch targets. Manifest identifiers, destinations and transport summaries wrap in constrained layouts.

## Existing rules retained

Inbound bay assignment is optional and does not record receipt or change inventory. Counts and quality checks remain in blind receiving. Incoming transfers cannot be received before transport arrival. Outbound release requires loading at a valid bay and assigned transport; driver arrival remains separate from destination acceptance. These client controls supplement existing server authorization and shipment guards.

## Verification and limits

Focused dock component, history and mutation tests cover receiving navigation without exposing counts, release prerequisites, failed refreshes, invalid site/bay requests and duplicate submissions. TypeScript and file-size checks pass. Full suite retains the pre-existing 98 failures.

No schema or database changes were made in this dock pass. Existing server dock occupancy, concurrent multi-device release and role/country policies have not been re-certified against staging in this pass. Actual mobile hardware and scanner behavior remain unverified. The separate pending atomic PACK-to-DISPATCH migration remains unapplied; this audit does not resolve that packing dependency.
