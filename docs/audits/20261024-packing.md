# Packing audit — 24 October 2026

## Local fixes

- Item persistence now updates local state after the save confirms and propagates failures to the scanner. Failed saves no longer appear as packed items.
- Scanner saves and completion have duplicate-submit locks; success feedback blocks rapid repeat submissions.
- Product lookup remains within the packing facility and prefers the manifest lot/bin.
- Packing handlers reject non-finite, zero, partial and excess quantities before saving.
- Removed the button that copied expected weight into the physical scale reading.
- Scanner content can scroll on constrained screens and quantity layouts can shrink.
